# 渲染管线 1.0.0

参数的完整字段、范围、默认值分别见 `protocol/parameters.schema.json` 和 `default_parameters.json`。拒绝未知版本、缺失字段、非有限数字、不合法曲线或越界值；不会猜测新版参数的含义。除几何操作外，以下数学在两平台同一个 C++ 模块执行。

## 约定

输入为方向已归一化、ICC 转为 **SDR sRGB** 的非预乘 RGBA8。alpha 原样保留；相机 JPEG 为不透明。无 ICC 的 SDR 图解释为 sRGB。解码器负责设备色彩配置；不把 P3 数字直接当 sRGB。HDR 和 RAW 显影不是本版本的工作空间。运算使用 float，局部积分和使用 double，仅在最终 RGBA8 输出量化。不会在每个滑块之间进行 JPEG 编解码。

记 `clip(x)=min(1,max(0,x))`，`S(a,b,x)=t²(3−2t)`，其中 `t=clip((x−a)/(b−a))`。亮度函数 `Y=.2126R+.7152G+.0722B`。UI 数值除 exposure、hue、seed 和几何外均为明确范围的相对调整量，不是 Kelvin。

## 固定顺序和映射

1. **方向、ICC 和几何**：读 EXIF，正确旋转/镜像；ICC 转 sRGB。`crop=[left,top,right,bottom]` 是归一化原图边界，左上向下取整，右下向下取整，最小 1 像素；裁切后再顺时针旋转 0/90/180/270°。原文件不改写。平台完成后，传入核心的 geometry 必须是 identity。
2. **sRGB → linear**：标准分段 EOTF：`c/12.92`（c≤.04045），否则 `((c+.055)/1.055)^2.4`。
3. **白平衡及曝光**：Exposure 范围 −5…+5 EV，增益 `2^EV`。令 t=temperature_shift/100，m=tint/100，RGB 增益为 `2^(.5t−.15m)`、`2^(.3m)`、`2^(−.5t−.15m)`。这是相对原采集白平衡的 RGB 调整，无色温计标定。
4. **基础影调**：先按曝光/白平衡后的 Y 计算 `sh=1−S(0,.65,Y)`、`hi=S(.35,1,Y)`。每通道乘 `2^(.7*(highlights*hi+shadows*sh)/100)`。设该结果为 v，再加 `whites/100*.25*S(.5,1,v)` 与 `blacks/100*.15*(1−S(0,.35,v))`。对比度：`(v−.18)*2^(contrast/100)+.18`；然后裁到 SDR [0,1]。
5. **linear → sRGB**：标准分段 OETF；低段阈值 .0031308，系数 12.92；高段 `1.055*v^(1/2.4)−.055`。从这里继续使用 float sRGB 值。
6. **曲线**：先 RGB 主曲线，再对应通道曲线。2…32 点；x 严格增加且相邻至少 .0001，首末 x=0 和 1；y∈[0,1]。每段用三次 Hermite。斜率 `d_i=(y_(i+1)−y_i)/h_i`，两端取相邻割线；内点异号/零取 0，否则取加权调和平均 `(w1+w2)/(w1/d_(i−1)+w2/d_i)`，w1=2h_i+h_(i−1)，w2=h_i+2h_(i−1)。输出受限 [0,1]，避免无约束样条越界。曲线编辑器显示相同插值。
7. **HSL、自然饱和度及饱和度**：标准 RGB↔HSL。八色中心为 0、30、60、120、180、240、270、300°。循环距离 d<60° 时权重 `(.5+.5*cos(πd/60))`，其他为 0，最后归一化权重。色相偏移为加权 hue/100*30°；饱和度乘 `1+weighted_saturation/100` 并 clip；明度加 `weighted_luminance/100*.25` 并 clip（无彩色像素不因 HSL 明度选区调整而着色/改亮）。随后饱和度乘 `(1+saturation/100)*(1+vibrance/100*(1−S))` 并 clip，其中 S 是 HSL 调整后的饱和度。
8. **色彩分级**：sRGB 亮度 l，pivot=.5+balance/100*.2，width=.05+blending/100*.4。q=S(pivot−width,pivot+width,l)，mid=4q(1−q)，三个权重为 `(1−q)(1−mid)`、mid、`q(1−mid)`，和为 1。各区域将 hue 转换为满饱和、L=.5 的色向量 K，并减去其 Y 得到零亮度色向量。累加 `weight*(saturation/100*.25*(K−Y(K)) + luminance/100*.15)`。区域色相为 0…360°，强度 0…100；Balance 不是曝光量。
9. **Fade**：通道先 clip，再 `c*(1−fade/100*.3)+fade/100*.12`。选择在空间质感前执行，顺序在 JSON 中显式记录。
10. **锐度、清晰度、局部对比度**：均基于同一份前阶段 float 图。方形平均半径分别为 1、`clip_integer(floor(short_side/128),2,32)`、`clip_integer(floor(short_side/32),4,128)`。边缘只对存在的像素取均值。锐度加 `sharpness/100*clamp(c−blur1,−.08,.08)`；清晰度加 `clarity/100*.5*(c−blurC)`；局部对比加 `local_contrast/100*.5*(c−blurL)`。三者相加，不串联反馈。halo 覆盖启用的最大半径，瓦片边界不充当图像边界。
11. **暗角、颗粒**：nx=2(x+.5)/w−1、ny=2(y+.5)/h−1，暗角增益 `1+vignette/100*.75*S(.1,1,(nx²+ny²)/2)`。负值变暗，正值提亮。颗粒格点间距 `1+grain_size/100*7` 像素；整数格点通过固定 uint32 hash 和 seed 生成 [−1,1] 单色噪声，按 smoothstep 双线性混合，加 `noise*grain_amount/100*.08`。坐标是整幅图像坐标，不随瓦片改变。参考实现在 `core/src/g23.cpp`，hash 的两次乘法常量为 0x7feb352d 和 0x846ca68b。seed∈[0,2³²−1]，同输入尺寸、种子和参数重复输出相同。
12. **输出**：clip 到 [0,1]，乘 255 并 round 写 RGBA8；平台编码 sRGB PNG，无损保存最终 8-bit 学习目标；缩略图 JPEG 仅用于浏览。尚未提供 16-bit PNG。

预览与完整渲染使用相同代码。预览先缩小原图，空间半径相应缩放且受最小半径限制；颗粒大小以输出像素为单位。因此低分辨率预览与完整渲染并不逐像素相等，不能将预览 PNG 当作最终训练目标。

## 复现和性能

中性阶段可跳过，白平衡、曝光、对比增益和分级颜色按参数预计算，8-bit sRGB 解码表只缓存精确的 256 个输入值。不会用另一个算法替代最终输出。编译关闭 FMA 融合，不开启 fast-math。浮点库和解码器跨平台可能有末位差异；同一构建的重复性有测试，跨平台的逐字节一致性尚未在设备验证。

完整 CPU 渲染耗时可能较长；UI 使用低分辨率预览并丢弃过时请求。主机性能数据见验收报告。流畅度、功耗、热降频和连拍压力仍需真机测量；本版本不承诺 30fps 调色预览。

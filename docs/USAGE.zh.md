# G23 Lab 0.3 使用说明

## 选择胶卷色调并拍照

1. 相机顶部原来的“G23 LAB”已经替换为 LUT 选择按钮，显示当前胶卷名称。点击进入“胶卷色调”。
2. 上下拨动右侧半圆转盘。圆柱暗盒是不同 LUT 的临时外观；左侧中间的箭头指向当前胶卷，半圆中央显示名称，名称随档位改变。
3. 松手后自动吸附到完整档位；快速拨动有短距离惯性，经过档位时发出轻微触觉反馈。震动遵循手机的触觉设置，实际手感需真机体验。
4. 点“使用并返回拍摄”，或点返回，保存当前选择。应用重新打开后仍记住上次的 LUT。
5. 点底部中央快门。应用保留原始 JPEG，自动生成应用此 LUT 的完整尺寸 PNG，然后回到取景界面。无需再进入编辑器手动保存。

本轮 LUT 在拍摄后的保存阶段应用，实时取景目前显示原始画面。压缩包中的 15 个 33³ `.cube` 已全部接入，名称与文件内容保持原样。没有把圆柱外观当作实际调色预览。

## 相册只看照片

点相机左下角“相册”。相册是三列照片网格，移除了筛选、状态、勾选、数据、调色、导出和删除控件。点击照片可全屏查看，左右滑动浏览，双指缩放、双击放大或复位。

相册显示已生成的调色成片；旧版未处理的普通草稿仍可显示原图。新拍的 LUT 照片如处理失败，会保留原文件并报错，不把未完成的原图冒充已套色成片。

## 原图、调色数据和导出

照片仍保存在应用私有相册 `files/samples/G23_<编号>/`，不自动写入系统相册。覆盖安装通常保留数据，卸载会删除私有照片，卸载前应导出。

原有实验工具已移到相机右上角“设置”的“照片工具”：

- **最近照片的调色与数据**：打开最近照片的编辑器，可查看原图/成片、并列参数、统计、标签和预设，也可单张导出。
- **导出全部照片与分析**：生成 ZIP 并打开系统“另存为”，选择“下载”等文件夹保存；保存成功后可直接发送文件。

每张新照片固定保存拍摄时的 `look.json` 和原始 `look.cube`。后来换胶卷不会修改旧照片；编辑和导出都从原始 JPEG 重新渲染，LUT 只套用一次，不把已套色的 PNG 再套一遍。

| 文件 | 内容 |
|---|---|
| `original.jpg` | 完整原始 JPEG |
| `edited.png` | 完整尺寸调色成片 |
| `look.json` | 该照片的 LUT 名称、编号、SHA-256、网格大小和处理版本 |
| `look.cube` | 拍摄时绑定的原始 LUT 文件，供复现 |
| `original_parameters.json`、`parameters.json` | 中性原始基线与当前基础调色参数 |
| `comparison.json` | 并列参数、拍摄记录、图像统计和绑定的 LUT 记录 |
| `metadata.json`、`manifest.json`、`dataset.jsonl` | 拍摄信息、校验值、样本及 LUT 文件引用 |

旧版照片没有 LUT 绑定时，继续按旧流程显示和编辑，不会自动套上当前选择的胶卷。LUT 处理独立记录为 `cube_srgb_trilinear_1.0`：在基础调色 1.0.0 之后，对编码 sRGB 做三线性插值。

## 电脑分析和复现

```bash
python3 -m tools.g23_dataset analyze ./G23.zip --report ./report.html
python3 -m tools.render original.jpg parameters.json recreated.png --lut look.cube
```

先安装 `tools/requirements.txt` 并构建共享引擎。桌面复现沿用相同的 C++ LUT 实现；跨设备解码器差异仍可能影响逐像素一致性。

[胶卷选择器预览](images/lut-picker-0.3.png) 来自 Android 原生控件测试渲染，不是真机截图或实际取景证据。鸿蒙源码同步了选择器、照片相册、LUT 处理和文件记录；当前环境没有鸿蒙 SDK，尚未编译或真机验证。

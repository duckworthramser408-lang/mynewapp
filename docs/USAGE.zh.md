# G23 相机 0.4 使用说明

这一版用于拍照出图，没有实验调色台、参数表、分析报告或数据包导出。

## 安装

在电脑浏览器点击仓库 README 的 APK 下载链接。GitHub 若提示无法预览，点“下载原始文件／Download raw file”。把 APK 传到 Android 手机安装；鸿蒙 NEXT 不能安装 APK，需要另外编译原生 HAP。允许相机权限后即可拍照。

包名 `lab.g23` 与当前开发签名延续旧版，可尝试覆盖升级。应用内照片位于私有存储，卸载会清除它们；先把需要保留的图片另存到系统相册。

## 选择胶卷并拍摄

拍摄页顶部是当前 LUT 的选择按钮。打开后，右侧半圆上的圆柱胶卷暗盒可以上下拨动；左侧箭头对准的胶卷就是当前选择。名称随拨动变化，吸附时提供系统允许的轻微触觉反馈。

点“使用并返回拍摄”，再按屏幕下方中间的快门。每张照片使用按下快门时的胶卷和画幅，之后换胶卷不会改变已拍照片。实时取景目前不带 LUT。

照片文件写入后快门恢复，冲洗任务独立处理；等待胶片出图时可以继续拍摄。快门只会在相机正在获取这一张 JPEG 的短时间内暂时不可用。多张照片按顺序冲洗，避免多个完整大图同时占用内存。

设置保留构图网格和曝光补偿开关。没有“最近照片的调色与数据”或“导出全部照片与分析”。

## 相册、预览与删除

点拍摄页左下角的“相册”。相册为三列照片网格，处理中显示一张胶卷暗盒和“冲洗中”，完成后自动替换为照片。

点击照片打开预览。原片在竖线左侧、胶片在右侧，按住竖线或中间圆形手柄左右拖动，可查看任意比例的前后效果。两张图使用相同裁切和缩放。支持双指缩放；Android 还可以在竖线以外左右滑动浏览其他照片。

未完成冲洗时可以预览和保存原片，胶片保存要等冲洗完成。失败时原片仍保留，预览下方“冲洗未完成 · 点此重新冲洗”可重试。

长按网格照片，或点预览右上角的删除图标，确认后删除应用内原片和胶片。正在冲洗的照片同样可以删除，后台任务不会重新把它加回来。已另存到系统相册的副本保留。

## 保存图片

点“保存图片”，选择“保存原片”或“保存胶片”。

- 原片：相机输出的 JPEG，未套 LUT；直接复制保留原始文件。Android 新拍照片由 CameraX 按选择的画幅裁切；鸿蒙及旧照片的原片保留相机原始构图，预览按胶片画幅对齐。
- 胶片：应用拍摄时所选 LUT 后的高质量 JPEG，质量 95，按选择的画幅输出，不额外降低分辨率。它使用有损 JPEG，原片始终另存。旧版已生成的 PNG 则按 PNG 保存。

Android 10 及以上直接保存到系统相册的 `Pictures/G23`，不需要读取其他相册照片的权限。Android 9 使用系统“另存为”选择位置。鸿蒙原生界面先选择原片／胶片，再点击系统安全保存按钮，写入系统图库；该源码尚待目标 SDK 编译和真机验证。

应用内相册与手机系统相册是两个位置。拍照先进入应用相册；另存后的照片可在手机系统相册找到。全自动写入鸿蒙图库的能力和限制见[专项分析](HARMONY_GALLERY.md)。

## 中断与恢复

Android 使用持久化后台任务，关闭或重建拍摄界面不取消冲洗；进程被系统结束后由 WorkManager 和下次启动时的检查恢复。系统后台调度、强行停止应用或存储不足可能延后完成，不承诺退出后即时出图。

鸿蒙源码使用应用级串行队列，LUT 解析使用 TaskPool，像素处理使用异步 N-API。界面保持打开时可继续拍摄；系统结束进程后在下次启动恢复，不声明已经具备鸿蒙长期后台运行能力。

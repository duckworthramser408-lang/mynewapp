# G23 Lab 0.2 使用说明

## 拍照与找照片

打开后允许相机权限。底部中央白色圆形按钮拍照，左下角“相册”查看本机照片，右下角翻转摄像头。顶部可控制闪光、进入中文设置；画幅和网格在取景框下方。

拍摄后自动打开调色页。完整原始 JPEG 保存在应用私有相册 `files/samples/G23_<编号>/original.jpg`，调色不会覆盖它。系统相册不会自动出现这些照片；需要通过“一键导出”选择系统文件位置。卸载应用会删除私有相册，卸载前请导出。兼容更新安装通常保留数据，需相同签名和包名。

## 调色和查看并列数据

- 编辑器默认左侧原图、右侧调色结果，使用相同构图方便比较。双指缩放、拖动，长按查看原图；顶栏对比图标切换滑动分割模式。
- 点击“基础 / 分色 / 曲线 / 分级 / 质感 / 裁切”，拖动对应中文滑块。点击滑块标题恢复该项默认值；顶栏可撤销、重做、整体重置。
- “并列数据”按“参数 / 原始 / 调色后”三列显示完整快照，变化的值用浅绿标记。拍摄感光度、快门、光圈属于同一次拍摄记录，两侧共用，不会伪造调色后的拍摄值。
- “保存成片”生成完整尺寸 PNG 和图像统计。长按该按钮可明确确认为训练样本。普通保存与导出不会把草稿自动确认为训练标签。
- 图像统计比较相同裁切/旋转范围，包含平均 RGB、亮度、饱和度、暗部/高光占比及 64 档亮度直方图。固定网格每侧最多 256×256 个采样点；这是编码 sRGB 的描述性统计，并非传感器 RAW 测量或色彩校准结果。

## 一键导出与发送

1. 单张：调色页底部点“一键导出”。多张：在相册勾选照片后点“一键导出 · 保存到文件”；未勾选时导出当前筛选结果（包含其他分页）。
2. 应用会先保存当前完整尺寸成片和分析快照，再打开系统“另存为”。选择“下载”等目录并点保存；取消选择不会删除本机照片。
3. 保存后可点“发送文件”，通过系统分享发送 ZIP。也可在系统文件管理器找到刚保存的 ZIP 后发送。
4. 只需要数据时，打开“并列数据”→“保存分析文件”，另存为 JSON，不含照片像素。

ZIP 中重点文件：

| 文件 | 内容 |
|---|---|
| `samples/G23_编号/original.jpg` | 完整原始 JPEG |
| `edited.png` | 完整尺寸调色结果 |
| `original_parameters.json` | 不随调色改变的中性原始基线 |
| `parameters.json` | 当前最终调色参数，含曲线、构图及颗粒种子 |
| `comparison.json` | 同一编号的原始/调色快照、逐项并列值和两侧图像统计 |
| `metadata.json` | 真实可取得的拍摄参数、场景、评分和校验值 |
| `reports/before_after_parameters.csv` | Excel 可读取的逐参数原始/调色对照表，包含曲线与裁切数组 |
| `dataset.jsonl`、`manifest.json` | 配对索引和 SHA-256 校验 |

设置中的“导出时移除定位信息”默认关闭，便于保留原始分析文件。开启后仅修改导出的 JPEG 副本，并省略可能带位置的 DNG；本机原图不变。

0.1 版旧照片仍可打开。首次保存或一键导出会补齐中性基线与分析文件，使用同一 1.0.0 调色管线重新生成衍生图；JPEG 原文件保持不变。未知管线版本会被拒绝，不会自动解释。

## 电脑分析

```bash
python3 -m tools.g23_dataset analyze ./G23_影像分析.zip --report ./report.html
```

安装 `tools/requirements.txt` 后运行。浏览器打开报告可并列查看图片、展开参数表；ZIP 中的 CSV 也可直接导入 Excel。电脑网页版用于下载 APK 和查看代码，拍摄、调色需在 Android 手机上安装运行。

鸿蒙原生源码同步了本轮布局、中文参数与文件保存；当前环境没有鸿蒙 SDK，尚未编译或真机验证。Android 也仍需要相机、RAW 及系统文件选择器的真机验收。
